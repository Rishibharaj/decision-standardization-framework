# Decision Intelligence Framework

A structured approach for converting unstructured communications into standardized outcomes.

The framework evolved through two phases:

## Phase 1

Rule-Based Classification

Keywords → Categories → Precedence Rules → Outcomes

## Phase 2

Intent Detection

Keywords → Context → Intent → Outcomes

Core Principle:

Messy Inputs
↓
Standardized Logic
↓
Consistent Decisions
↓
Automation Opportunity
