# Supporting Tooling

The Decision Standardization Framework is supported by a collection of analytical tools used for signal discovery, signal refinement, audit preparation, and framework maintenance.

These tools support implementation and continuous improvement activities but are not required for operation of the framework itself.

## Available Tools

- Keyword & Phrase Extraction
- Anchor-Driven Phrase Expansion
- Heatmap Analysis
- Audit Sampling Templates
- Confidence Assessment Tools

## Purpose

These tools were developed to improve signal coverage, support governance activities, and accelerate framework maintenance in restricted environments.
