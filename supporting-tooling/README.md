# Supporting Tooling

The Decision Standardization Framework is supported by a collection of analytical tools used for signal discovery, refinement, audit preparation, and framework maintenance.

These tools support implementation and continuous improvement activities but are not required for operation of the framework itself.

## Available Tools

### Keyword & Phrase Discovery

Identifies keywords, bigrams, trigrams, and contextual phrases from historical communications to support signal discovery and refinement.

File:
`Keyword-Phrase-Extraction.md`

### Anchor-Driven Phrase Expansion

Expands analyst-defined anchor phrases by identifying contextual variations occurring before and after the anchor phrase.

File:
`Anchor-Driven-Phrase-Expansion.bas`

## Purpose

Supporting tools help:

- Discover emerging decision signals
- Improve signal coverage
- Refine category mappings
- Support audit activities
- Maintain the Signal Interpretation Layer
